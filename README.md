🚀 Executando o projeto

Clone o repositório:

git clone SEU_LINK_DO_REPOSITORIO

Entre na pasta:

cd portfolio-react

Instale as dependências:

npm install

Execute o projeto:

npm run dev

Depois, acesse no navegador o endereço indicado pelo Vite.
